# Speed Money — Collection Agent App

Standalone mobile prototype for on-field collection and recovery agents.

## Features
- **12 Screens** covering daily collection quota, assigned customer visits, cash receipt counting, customer OTP verification, digital canvas signature capture, collection receipts, cash ledger, and bank cash deposit proof.
- Built with React 19, TanStack Router, and Tailwind CSS v4.
- Includes a floating **All Screens** switcher for review and presentation.

## Getting Started

```sh
npm install
npm run dev
```

The app will be accessible at `http://localhost:8083/`.

## Build

```sh
npm run build
npm run preview
```
