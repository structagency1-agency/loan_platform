# Speed Money — Admin App

Standalone desktop management portal for loan officers, branch managers, and administrators.

## Features
- **21 Screens** covering loan underwriting, customer management, disbursements, EMI schedules, agent assignment, cash collection reconciliation, analytics reports, and audit logs.
- Built with React 19, TanStack Router, Recharts, and Tailwind CSS v4.
- Includes a floating **All Screens** switcher for review and presentation.

## Getting Started

```sh
npm install
npm run dev
```

The app will be accessible at `http://localhost:8082/`.

## Build

```sh
npm run build
npm run preview
```
