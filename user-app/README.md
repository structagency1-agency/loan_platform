# Speed Money — User App

Standalone mobile prototype for borrowers and loan applicants.

## Features
- **30 Screens** covering onboarding, personal loans, agri loans, property loans, KYC, document uploads, application tracking, 12-month EMI repayment schedule, UPI payments, and receipts.
- Built with React 19, TanStack Router, and Tailwind CSS v4.
- Includes an ergonomic, conflict-free bottom navigation and a floating **All Screens** switcher for review and presentation.

## Getting Started

```sh
npm install
npm run dev
```

The app will be accessible at `http://localhost:8081/`.

## Build

```sh
npm run build
npm run preview
```
